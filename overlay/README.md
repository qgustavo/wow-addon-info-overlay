# WowQuickRef Overlay

From this folder run `npm install` then `npm start`.
To skip the terminal: double-click `start-overlay.vbs`. To start with Windows, run `install-autostart.ps1`.
To build a portable exe: `npm run dist` (or `pack-release.cmd` at the repo root). A push to `main` publishes it on GitHub Releases.
F8 toggles visibility. Choose spec in the dropdown (last pick is saved).
Always-on-top, frameless, ~30% of primary width, docked to the right.
Requires borderless-windowed World of Warcraft. No in-game addon.
